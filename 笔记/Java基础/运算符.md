# Java 运算符学习笔记

## 一、算术运算符

### 1.1 基本算术运算符

| 运算符 | 作用 | 示例 |
|-------|------|------|
| `+` | 加法 | `10 + 3 = 13` |
| `-` | 减法 | `10 - 3 = 7` |
| `*` | 乘法 | `10 * 3 = 30` |
| `/` | 除法 | `10 / 3 = 3` |
| `%` | 取模（取余数） | `10 % 3 = 1` |

### 1.2 整数运算注意事项

```java
int a = 10;
int b = 3;

System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3（整数相除，结果还是整数，小数部分丢失）
System.out.println(a % b);  // 1（取余数）
```

**重要规则：**
- 整数与整数运算，结果一定是整数
- 整数相除会直接舍弃小数部分

### 1.3 小数运算注意事项

```java
double c = 10.0;
double d = 3.0;

System.out.println(c + d);  // 13.0
System.out.println(c - d);  // 7.0
System.out.println(c * d);  // 30.0
System.out.println(c / d);  // 3.3333333333333335
System.out.println(c % d);  // 1.0
```

**注意：** 小数直接参与运算，结果可能是不准确的（浮点数精度问题）

## 二、取模运算符的应用

### 2.1 数字拆分

**公式：**
```java
个位：数值 % 10
十位：数值 / 10 % 10
百位：数值 / 100 % 10
千位：数值 / 1000 % 10
```

**示例：拆分三位数**
```java
import java.util.Scanner;

public class NumberSplit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个三位数：");
        int num = sc.nextInt();
        
        int hundreds = num / 100 % 10;  // 百位
        int tens = num / 10 % 10;       // 十位
        int units = num % 10;           // 个位
        
        System.out.println("百位: " + hundreds);
        System.out.println("十位: " + tens);
        System.out.println("个位: " + units);
    }
}
```

### 2.2 时间单位换算

**题目：** 将秒数转换为时:分:秒格式

**公式：**
```java
小时 = 总秒数 / 3600
分钟 = 总秒数 % 3600 / 60
秒 = 总秒数 % 60
```

**示例：**
```java
int seconds = 3661;

int hours = seconds / 3600;        // 1
int minutes = seconds % 3600 / 60; // 1
int sec = seconds % 60;            // 1

System.out.println(hours + "时" + minutes + "分" + sec + "秒");  // 1时1分1秒
```

## 三、类型转换

### 3.1 隐式转换（自动类型提升）

**规则：** 小范围类型自动转换为大范围类型

```
byte -> short -> int -> long -> float -> double
```

**特殊情况：**
- byte 或 short 参与运算时，会先提升为 int 类型

```java
byte a = 10;
byte b = 20;
int c = a + b;  // byte + byte 会自动提升为 int
```

### 3.2 强制转换

**规则：** 大范围类型转换为小范围类型，需要手动转换

**格式：**
```java
目标数据类型 变量名 = (目标数据类型) 被转换的变量;
```

**示例：**
```java
int x = 10;
byte d = (byte) x;  // 强制转换为 byte

byte e = 10;
byte f = 20;
byte g = (byte) (e + f);  // 注意：需要加括号，先计算再转换
```

### 3.3 类型转换练习

**练习一：**
```java
byte b = 100;
short s = 200;
double d = 20.3;

// b -> int -> double
// s -> int -> double
// 最终结果为 double 类型
double result = b + s + d;  // 320.3
```

**练习二：**
```java
short s1 = 100;
short s2 = 200;

// 错误写法：short + short 会提升为 int，不能直接赋值给 short
// short result = s1 + s2;  // 编译错误

// 正确方案一：强制转换为 byte（可能导致数据丢失）
byte result1 = (byte)(s1 + s2);

// 正确方案二：使用 int 接收结果
int result2 = s1 + s2;
```

## 四、ASCII 码表

### 4.1 常用 ASCII 码值

| 字符 | ASCII 码值 |
|------|----------|
| 'A' | 65 |
| 'a' | 97 |
| '0' | 48 |

**规律：**
- 大写字母 'A' 到 'Z'：65 ~ 90
- 小写字母 'a' 到 'z'：97 ~ 122
- 数字字符 '0' 到 '9'：48 ~ 57
- 大写字母与对应小写字母的差值：32

### 4.2 大小写转换示例

```java
public class CaseConvert {
    public static void main(String[] args) {
        // 大写转小写
        char big = 'A';      // ASCII: 65
        char small = (char)(big + 32);  // 65 + 32 = 97 -> 'a'
        System.out.println(small);  // a
        
        // 小写转大写
        char lower = 'b';   // ASCII: 98
        char upper = (char)(lower - 32);  // 98 - 32 = 66 -> 'B'
        System.out.println(upper);  // B
    }
}
```

## 五、字符串拼接

### 5.1 字符串拼接规则

**关键规则：** 当表达式中出现字符串时，`+` 变为拼接操作

```java
System.out.println(10 + 8 + "岁");    // "18岁"（先计算 10+8，再拼接）
System.out.println(10 + "岁" + 8);    // "10岁8"（先拼接 10+"岁"，再拼接 8）
```

### 5.2 字符串拼接陷阱

```java
System.out.println(10 + 8 + "岁" + 1 + 2);  // "18岁12"
// 解释：
// 1. 10 + 8 = 18
// 2. 18 + "岁" = "18岁"
// 3. "18岁" + 1 = "18岁1"  （字符串出现后，后续全为拼接）
// 4. "18岁1" + 2 = "18岁12"
```

### 5.3 字符串变量

```java
String a = "我";
System.out.println("字符串是" + a);  // "字符串是我"
```

## 七、自增自减运算符

### 7.1 基本概念

| 运算符 | 作用 | 说明 |
|-------|------|------|
| `++` | 自增 | 变量值加1 |
| `--` | 自减 | 变量值减1 |

### 7.2 前置与后置区别

```java
int a = 10;

// 后置++：先使用，后加1
int b = a++;  // b=10, a=11

// 前置++：先加1，后使用
int c = ++a;  // c=12, a=12

// 后置--：先使用，后减1
int d = a--;  // d=12, a=11

// 前置--：先减1，后使用
int e = --a;  // e=10, a=10
```

**记忆口诀：**
- `++`在前，先加后用
- `++`在后，先用后加

## 八、关系运算符（比较运算符）

### 8.1 常用关系运算符

| 运算符 | 作用 | 示例 | 结果 |
|-------|------|------|------|
| `==` | 等于 | `10 == 10` | `true` |
| `!=` | 不等于 | `10 != 10` | `false` |
| `>` | 大于 | `10 > 5` | `true` |
| `>=` | 大于等于 | `10 >= 10` | `true` |
| `<` | 小于 | `10 < 5` | `false` |
| `<=` | 小于等于 | `10 <= 5` | `false` |

### 8.2 关系运算符练习

**练习一：比较两人身高**
```java
import java.util.Scanner;

public class HeightCompare {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("请输入我的身高：");
        double myHeight = sc.nextDouble();
        
        System.out.println("请输入你兄弟的身高：");
        double broHeight = sc.nextDouble();
        
        // 比较两个身高
        boolean result = myHeight >= broHeight;
        System.out.println("我比兄弟高？" + result);
    }
}
```

**练习二：判断是否能被3整除**
```java
import java.util.Scanner;

public class DivisibleByThree {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个三位数：");
        int num = sc.nextInt();
        
        // 拆分各位数字
        int ge = num % 10;
        int shi = num / 10 % 10;
        int bai = num / 100 % 10;
        
        // 计算各位数字之和
        int sum = ge + shi + bai;
        
        // 判断是否能被3整除
        boolean result = sum % 3 == 0;
        System.out.println("各位数字之和能被3整除？" + result);
    }
}
```

## 九、逻辑运算符

### 9.1 基本逻辑运算符

| 运算符 | 作用 | 说明 | 示例 |
|-------|------|------|------|
| `&` | 与（AND） | 两边都为true，结果才为true | `true & false = false` |
| `\|` | 或（OR） | 两边有一个为true，结果就为true | `true \| false = true` |
| `!` | 非（NOT） | 取反，true变false，false变true | `!true = false` |
| `^` | 异或（XOR） | 两边不同为true，相同为false | `true ^ false = true` |

### 9.2 短路逻辑运算符（推荐使用）

| 运算符 | 作用 | 特点 |
|-------|------|------|
| `&&` | 短路与 | 左边为false，右边不执行 |
| `\|\|` | 短路或 | 左边为true，右边不执行 |

**优势：** 效率更高，避免不必要的计算

### 9.3 逻辑运算符练习

**练习一：判断数字是否在1-10之间**
```java
import java.util.Scanner;

public class NumberInRange {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个整数：");
        int num = sc.nextInt();
        
        // 使用短路与&&判断范围
        boolean result = (num >= 1 && num <= 10);
        System.out.println("数字在1-10之间？" + result);
    }
}
```

**练习二：判断数字是否不在1-10之间**
```java
import java.util.Scanner;

public class NumberNotInRange {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个整数：");
        int num = sc.nextInt();
        
        // 方法一：使用非运算符
        boolean result1 = !(num >= 1 && num <= 10);
        
        // 方法二：使用短路或||
        boolean result2 = num < 1 || num > 10;
        
        System.out.println("方法一结果：" + result1);
        System.out.println("方法二结果：" + result2);
    }
}
```

### 9.4 逻辑运算符应用场景

- **登录验证：** 用户名和密码同时验证 (`&&`)
- **多条件选择：** 扫码登录或账号密码登录二选一 (`||`)
- **权限检查：** 同时满足多个条件 (`&&`)

## 十、赋值运算符

### 10.1 常用赋值运算符

| 运算符 | 作用 | 示例 | 等价于 |
|-------|------|------|-------|
| `=` | 直接赋值 | `a = 10` | - |
| `+=` | 加后赋值 | `a += b` | `a = a + b` |
| `-=` | 减后赋值 | `a -= b` | `a = a - b` |

| `/=` | 除后赋值 | `a /= b` | `a = a / b` |
| `%=` | 取模后赋值 | `a %= b` | `a = a % b` |

### 10.2 赋值运算符示例

```java
int a = 10;
int b = 20;

a += b;  // a = a + b = 30
System.out.println(a);  // 30
System.out.println(b);  // 20

int c = 10;
int d = 21;

d %= c;  // d = d % c = 1
System.out.println(c);  // 10
System.out.println(d);  // 1
```

## 十一、三元运算符

### 11.1 语法格式

```
条件表达式 ? 表达式1 : 表达式2
```

**执行流程：**
- 如果条件为true，返回表达式1的值
- 如果条件为false，返回表达式2的值

### 11.2 三元运算符示例

**示例：求两个数的最大值**
```java
int a = 10;
int b = 20;

// 使用三元运算符求最大值
int max = a > b ? a : b;
System.out.println("最大值：" + max);  // 20
```

**示例：判断奇偶数**
```java
int num = 15;

// 使用三元运算符判断奇偶
String result = num % 2 == 0 ? "偶数" : "奇数";
System.out.println(num + "是" + result);  // 15是奇数
```

## 十二、综合练习

### 12.1 回文数判断

**题目：** 判断一个四位数是否为回文数

**回文数定义：** 正读和倒读都相同的数字，如1221、3443

```java
import java.util.Scanner;

public class PalindromeNumber {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个四位整数：");
        int num = sc.nextInt();
        
        // 拆分各位数字
        int ge = num % 10;           // 个位
        int shi = num / 10 % 10;     // 十位
        int bai = num / 100 % 10;    // 百位
        int qian = num / 1000 % 10;  // 千位
        
        // 判断是否为回文数：个位等于千位，十位等于百位
        boolean result = ge == qian && shi == bai;
        System.out.println(num + "是回文数？" + result);
    }
}
```

### 12.2 7的有缘数

**题目：** 判断一个两位数是否为7的有缘数

**定义：** 只要数字包含7或者是7的倍数，则为有缘数

```java
public class LuckyNumber {
    public static void main(String[] args) {
        int num = 34;
        
        // 拆分十位和个位
        int ge = num % 10;
        int shi = num / 10 % 10;
        
        // 判断是否为7的有缘数
        boolean result = ge == 7 || shi == 7 || num % 7 == 0;
        System.out.println(num + "是7的有缘数？" + result);
    }
}
```
