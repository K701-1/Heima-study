# Java内存与运行机制知识点总结

## 一、Java运行机制
### 1. 程序执行流程
Java程序采用**编译+解释**的执行模式，完整流程为：
1.  编写 `.java` 后缀的Java源文件
2.  通过编译器编译生成 `.class` 字节码文件
3.  字节码文件在JVM（Java虚拟机）中运行，最终输出程序结果

### 2. JVM与跨平台特性
- Java程序**不直接运行在操作系统上**，而是运行在对应系统的JVM中
- 不同操作系统（Windows、macOS、Linux等）有专属版本的JVM
- 核心价值：实现**一次编写、到处运行**的跨平台能力，一套代码可在任意安装了JVM的系统中运行

## 二、内存基础概念
### 1. 内存的定义与作用
- 内存是软件运行时**临时存储数据**的空间，读写速度远快于硬盘
- 核心操作：① 将数据存入内存对应位置；② 按内存地址取出并使用数据
- 与硬盘的区别：内存是临时存储，程序关闭后数据清空；硬盘负责持久化保存数据

### 2. 内存地址
- 本质：内存中每个最小存储单元（1字节）的唯一编号，用于快速定位和管理内存空间
- 表示规则：
    - 32位操作系统：用32位二进制数表示地址，最大支持4GB内存（2^32字节）
    - 64位操作系统：用64位二进制数表示地址，理论可支持超大内存空间；为便于阅读，通常转换为十六进制形式展示

## 三、JVM内存分配
### 1. 五大内存区域
JVM将内存划分为5个功能区域，核心常用的为前三个：

| 内存区域 | 线程归属 | 核心作用 |
| :--- | :--- | :--- |
| 栈内存 | 线程私有，每个线程独立栈 | 方法调用时进栈执行，执行完毕自动出栈；存储方法内的局部变量 |
| 堆内存 | 所有线程共享 | 存储所有通过`new`关键字创建的对象、数组，包含字符串常量池 |
| 方法区 | 所有线程共享 | 存储类的字节码信息、常量、静态变量；JDK7为永久代实现，JDK8+改为元空间，从虚拟机内部移至本地内存 |
| 本地方法栈 | 线程私有 | 执行本地Native方法时使用 |
| 程序计数器 | 线程私有 | 记录当前线程执行的字节码指令行号，用于线程切换后恢复执行位置 |

### 2. 两类数据类型的内存特性
#### （1）基本数据类型
- 变量中直接存储**真实的数据值**
- 方法传参时，传递的是数据值本身（值传递）
- 方法内修改参数值，不会影响方法外的原变量

#### （2）引用数据类型（数组、对象等）
- 栈中的变量存储的是**堆内存的地址值**
- 方法传参时，传递的是地址值（引用传递）
- 通过地址修改堆中的对象内容，所有指向该地址的变量都会同步感知到变化

### 3. 典型代码内存执行过程
1.  **仅含基本数据类型的程序**：仅使用栈内存+方法区；main方法进栈执行，变量直接存值，方法执行完毕栈帧弹出，数据释放。
2.  **包含数组的程序**：使用栈+堆+方法区；数组对象在堆中开辟空间并生成地址，栈中变量存储该地址；通过变量访问数组时，先通过地址找到堆中数组，再操作具体元素。

## 四、核心结论汇总
1.  Java程序运行流程：Java源文件 → 编译为class字节码文件 → JVM运行输出结果
2.  JVM内存分为5部分：栈、堆、方法区、本地方法栈、程序计数器
3.  栈负责方法执行，堆负责存储new出来的对象/数组，方法区存储字节码信息
4.  基本数据类型存真实值，传值不影响原变量；引用数据类型存地址值，传引用可修改原对象内容
