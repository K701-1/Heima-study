# Java 变量与基本数据类型学习笔记

## 一、变量基础概念

### 1.1 变量的定义
变量是用于存储数据的容器，可以理解为一个"盒子"，用来存放程序中需要使用的数据。

### 1.2 变量定义格式
```java
数据类型 变量名 = 数据值;
```

### 1.3 变量使用示例
```java
// 定义变量记录微信余额
double a = 0;
// 定义变量记录支付宝余额
double b = 10;
// 定义变量记录银行卡余额
double c = 20;

// 使用变量进行计算
System.out.println("现在一共有:" + (a + b + c) + "元");
```

---

## 二、变量的注意事项

1. **只能存一个值**
   - 一个变量同一时刻只能存储一个值

2. **变量名不允许重复定义**
   - 同一作用域内不能有同名变量

3. **变量在使用之前一定要进行赋值**
   ```java
   int a;
   a = 10;  // 必须先赋值
   System.out.println(a);  // 才能使用
   ```

4. **一条语句可以定义多个变量，也可以连续赋值**
   ```java
   // 一条语句定义多个变量
   int b, c, d;
   
   // 连续赋值
   b = c = d = 10;
   ```

## 三、Java 八种基本数据类型

### 3.1 整数类型

| 数据类型 | 关键字 | 字节数 | 范围 | 示例 |
|---------|-------|-------|------|------|
| 字节型 | byte | 1 | -128 ~ 127 | `byte b = 10;` |
| 短整型 | short | 2 | -32768 ~ 32767 | `short s = 23784;` |
| 整型 | int | 4 | -2^31 ~ 2^31-1 | `int i = 1234567890;` |
| 长整型 | long | 8 | -2^63 ~ 2^63-1 | `long l = 123456789012345L;` |

**注意：**
- long 类型需要以 `L` 或 `l` 结尾，建议大写 `L` 方便阅读
- int 是最常用的整数类型

### 3.2 浮点数类型（小数类型）

| 数据类型 | 关键字 | 字节数 | 示例 |
|---------|-------|-------|------|
| 单精度浮点数 | float | 4 | `float f = 123.45F;` |
| 双精度浮点数 | double | 8 | `double d = 123.45;` |

**注意：**
- float 类型需要以 `F` 或 `f` 结尾，建议大写 `F`
- double 是最常用的浮点数类型

### 3.3 字符类型

| 数据类型 | 关键字 | 字节数 | 示例 |
|---------|-------|-------|------|
| 字符型 | char | 2 | `char c = '中';` |

**注意：**
- char 类型使用单引号 `''` 包裹
- 可以存储一个中文字符（因为 Java 使用 Unicode 编码）

### 3.4 布尔类型

| 数据类型 | 关键字 | 字节数 | 示例 |
|---------|-------|-------|------|
| 布尔型 | boolean | 1 | `boolean bool = true;` |

**注意：**
- boolean 只有两个值：`true` 和 `false`
- 用于表示逻辑判断的结果

## 四、变量命名规范

1. **小驼峰命名法**（推荐用于变量名）
   - 第一个单词首字母小写，其他单词首字母大写
   - 例如：`myName`, `studentAge`, `getMaxValue`

2. **命名规则**
   - 由字母、数字、下划线 `_` 和美元符号 `$` 组成
   - 不能以数字开头
   - 不能使用 Java 关键字
   - 建议使用有意义的英文单词

## 五、键盘录入（Scanner）

### 5.1 使用步骤

1. **导入 Scanner 类**
   ```java
   import java.util.Scanner;
   ```

2. **创建 Scanner 对象**
   ```java
   Scanner sc = new Scanner(System.in);
   ```

3. **接收用户输入**
   ```java
   // 接收整数
   int num = sc.nextInt();
   
   // 接收浮点数
   double num2 = sc.nextDouble();
   
   // 接收字符串（不带空格）
   String str = sc.next();
   ```

### 5.2 完整示例
```java
import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        // 创建 Scanner 对象
        Scanner sc = new Scanner(System.in);
        
        // 提示用户输入
        System.out.println("请输入一个整数：");
        
        // 接收输入
        int num = sc.nextInt();
        
        // 输出结果
        System.out.println("您输入的数字是：" + num);
    }
}
```

## 六、实战练习

### 6.1 BMI 计算器

**公式：** BMI = 体重(kg) ÷ 身高(m)²

```java
import java.util.Scanner;

public class BMICalculator {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("请输入您的体重（kg）：");
        int weight = sc.nextInt();
        
        System.out.println("请输入您的身高（m）：");
        double height = sc.nextDouble();
        
        double BMI = weight / (height * height);
        System.out.println("您的BMI指数是：" + BMI);
    }
}
```

**BMI 标准参考：**
- 偏瘦：< 18.5
- 正常：18.5 ~ 23.9
- 偏胖：24 ~ 27.9
- 肥胖：≥ 28

### 6.2 游戏战斗伤害计算

```java
// 定义变量
int attack = 220;      // 攻击力
int defense = 80;      // 防御力
double blood = 1223.3; // 血量
double skill = 1.2;    // 技能加成

// 普攻伤害 = 攻击力 - 防御力
double damage1 = attack - defense;

// 技能伤害 = 攻击力 × 技能加成 - 防御力
double damage2 = attack * skill - defense;

// 更新血量
blood = blood - damage2;
```

### 6.3 键盘录入求和

```java
import java.util.Scanner;

public class SumDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("请键盘录入第二个整数");
        int num2 = sc.nextInt();
        
        int sum = num1 + num2;
        System.out.println("两个数的和是：" + sum);
    }
}
```

## 七、常见问题与注意事项

### 7.1 类型转换
- 整数默认类型是 `int`
- 浮点数默认类型是 `double`
- long 类型需要加 `L` 后缀
- float 类型需要加 `F` 后缀

### 7.2 运算注意事项
```java
// 整数除法会丢失小数部分
int a = 10 / 3;  // 结果是 3，不是 3.333...

// 浮点数除法保留小数
double b = 10.0 / 3;  // 结果是 3.333...
```

### 7.3 变量作用域
- 变量只在其定义的代码块 `{}` 内有效
- 同一作用域内不能定义同名变量
