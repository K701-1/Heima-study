# Java 运算符学习笔记

## 一、算术运算符

### 1.1 基本算术运算符

| 运算符 | 作用 | 示例 |
|-------|------|------|
| `+` | 加法 | `10 + 3 = 13` |
| `-` | 减法 | `10 - 3 = 7` |
| `*` | 乘法 | `10 * 3 = 30` |
| `/` | 除法 | `10 / 3 = 3` |
| `%` | 取模（取余数） | `10 % 3 = 1` |

### 1.2 整数运算注意事项

```java
int a = 10;
int b = 3;

System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3（整数相除，结果还是整数，小数部分丢失）
System.out.println(a % b);  // 1（取余数）
```

**重要规则：**
- 整数与整数运算，结果一定是整数
- 整数相除会直接舍弃小数部分

### 1.3 小数运算注意事项

```java
double c = 10.0;
double d = 3.0;

System.out.println(c + d);  // 13.0
System.out.println(c - d);  // 7.0
System.out.println(c * d);  // 30.0
System.out.println(c / d);  // 3.3333333333333335
System.out.println(c % d);  // 1.0
```

**注意：** 小数直接参与运算，结果可能是不准确的（浮点数精度问题）

## 二、取模运算符的应用

### 2.1 数字拆分

**公式：**
```java
个位：数值 % 10
十位：数值 / 10 % 10
百位：数值 / 100 % 10
千位：数值 / 1000 % 10
```

**示例：拆分三位数**
```java
import java.util.Scanner;

public class NumberSplit {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("请输入一个三位数：");
        int num = sc.nextInt();
        
        int hundreds = num / 100 % 10;  // 百位
        int tens = num / 10 % 10;       // 十位
        int units = num % 10;           // 个位
        
        System.out.println("百位: " + hundreds);
        System.out.println("十位: " + tens);
        System.out.println("个位: " + units);
    }
}
```

### 2.2 时间单位换算

**题目：** 将秒数转换为时:分:秒格式

**公式：**
```java
小时 = 总秒数 / 3600
分钟 = 总秒数 % 3600 / 60
秒 = 总秒数 % 60
```

**示例：**
```java
int seconds = 3661;

int hours = seconds / 3600;        // 1
int minutes = seconds % 3600 / 60; // 1
int sec = seconds % 60;            // 1

System.out.println(hours + "时" + minutes + "分" + sec + "秒");  // 1时1分1秒
```

## 三、类型转换

### 3.1 隐式转换（自动类型提升）

**规则：** 小范围类型自动转换为大范围类型

```
byte -> short -> int -> long -> float -> double
```

**特殊情况：**
- byte 或 short 参与运算时，会先提升为 int 类型

```java
byte a = 10;
byte b = 20;
int c = a + b;  // byte + byte 会自动提升为 int
```

### 3.2 强制转换

**规则：** 大范围类型转换为小范围类型，需要手动转换

**格式：**
```java
目标数据类型 变量名 = (目标数据类型) 被转换的变量;
```

**示例：**
```java
int x = 10;
byte d = (byte) x;  // 强制转换为 byte

byte e = 10;
byte f = 20;
byte g = (byte) (e + f);  // 注意：需要加括号，先计算再转换
```

### 3.3 类型转换练习

**练习一：**
```java
byte b = 100;
short s = 200;
double d = 20.3;

// b -> int -> double
// s -> int -> double
// 最终结果为 double 类型
double result = b + s + d;  // 320.3
```

**练习二：**
```java
short s1 = 100;
short s2 = 200;

// 错误写法：short + short 会提升为 int，不能直接赋值给 short
// short result = s1 + s2;  // 编译错误

// 正确方案一：强制转换为 byte（可能导致数据丢失）
byte result1 = (byte)(s1 + s2);

// 正确方案二：使用 int 接收结果
int result2 = s1 + s2;
```

## 四、ASCII 码表

### 4.1 常用 ASCII 码值

| 字符 | ASCII 码值 |
|------|----------|
| 'A' | 65 |
| 'a' | 97 |
| '0' | 48 |

**规律：**
- 大写字母 'A' 到 'Z'：65 ~ 90
- 小写字母 'a' 到 'z'：97 ~ 122
- 数字字符 '0' 到 '9'：48 ~ 57
- 大写字母与对应小写字母的差值：32

### 4.2 大小写转换示例

```java
public class CaseConvert {
    public static void main(String[] args) {
        // 大写转小写
        char big = 'A';      // ASCII: 65
        char small = (char)(big + 32);  // 65 + 32 = 97 -> 'a'
        System.out.println(small);  // a
        
        // 小写转大写
        char lower = 'b';   // ASCII: 98
        char upper = (char)(lower - 32);  // 98 - 32 = 66 -> 'B'
        System.out.println(upper);  // B
    }
}
```

## 五、字符串拼接

### 5.1 字符串拼接规则

**关键规则：** 当表达式中出现字符串时，`+` 变为拼接操作

```java
System.out.println(10 + 8 + "岁");    // "18岁"（先计算 10+8，再拼接）
System.out.println(10 + "岁" + 8);    // "10岁8"（先拼接 10+"岁"，再拼接 8）
```

### 5.2 字符串拼接陷阱

```java
System.out.println(10 + 8 + "岁" + 1 + 2);  // "18岁12"
// 解释：
// 1. 10 + 8 = 18
// 2. 18 + "岁" = "18岁"
// 3. "18岁" + 1 = "18岁1"  （字符串出现后，后续全为拼接）
// 4. "18岁1" + 2 = "18岁12"
```

### 5.3 字符串变量

```java
String a = "我";
System.out.println("字符串是" + a);  // "字符串是我"
```

## 六、运算符优先级（补充）

| 优先级 | 运算符 | 说明 |
|-------|-------|------|
| 1 | `()` | 括号，最高优先级 |
| 2 | `*` `/` `%` | 乘、除、取模 |
| 3 | `+` `-` | 加、减 |
| 4 | `=` | 赋值，最低优先级 |

**建议：** 复杂表达式使用括号明确运算顺序
