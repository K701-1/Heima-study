# Java 面向对象基础学习笔记

## 一、面向对象概述

### 1.1 类与对象

面向对象思想强调"**先定义一类事物，再描述该类下的具体个体**"。在 Java 中主要通过两种方式组织代码：

| 类型 | 作用 | 格式 |
|------|------|------|
| **JavaBean 类** | 描述一类事物的属性和行为 | `public class 类名 { ... }` |
| **测试类** | 含有 `main` 方法，用于创建对象并调用其成员 | `public class Test { public static void main(...) { ... } }` |

> 一个 `.java` 文件里只能有一个 `public` 类，且类名必须与文件名一致。

### 1.2 JavaBean 的两大组成

- **属性（成员变量）**：描述事物"是什么"，如名字、年龄。写在类中方法外。
- **行为（成员方法）**：描述事物"能干什么"，如吃饭、睡觉。

> **JavaBean 类中的方法不写 `static`**（`static` 属于测试类/工具类）。

## 二、只用属性描述对象

**对应文件：`ooptest1/Dog.java` + `ooptest1/Test.java`；`ooptest2/Student.java` + `ooptest2/Test.java`**

### 2.1 定义类（描述一类事物）

```java
public class Dog {
    // 属性（成员变量）
    String name;    // 名字
    int age;        // 年龄
    double weight;  // 体重
    String color;   // 颜色
}
```

### 2.2 创建对象并访问属性

**格式：** `类名 对象名 = new 类名();`

```java
public class Test {
    public static void main(String[] args) {
        Dog d1 = new Dog();
        d1.name = "旺财";
        d1.age = 2;
        d1.weight = 5.5;
        d1.color = "yellow";
        System.out.println(d1.name + " " + d1.age + " " + d1.weight + " " + d1.color);

        Dog d2 = new Dog();
        d2.name = "小黑";
        d2.age = 1;
        d2.weight = 4.0;
        d2.color = "black";
        System.out.println(d2.name + " " + d2.age + " " + d2.weight + " " + d2.color);
    }
}
```

### 2.3 常用属性类型选择

参考 `ooptest2/Student.java`：

```java
public class Student {
    String name;    // 姓名
    char sex;       // 性别（单字用 char）
    int age;        // 年龄
    double height;  // 身高（可能带小数用 double）
}
```

**要点：**
- 同一个类可以创建多个对象，每个对象的属性相互独立。
- 属性不赋值时会带**默认值**（引用类型 `null`，`int` 为 `0`，`double` 为 `0.0`，`char` 为 `'\u0000'`）。

## 三、给类添加行为（成员方法）

**对应文件：`opptest3/Teacher.java` + `opptest3/Test.java`；`opptest4/Cook.java` + `opptest4/Test.java`**

### 3.1 在 JavaBean 中定义方法

```java
public class Teacher {
    // 属性
    String name;
    int age;

    // 行为（成员方法，不写 static）
    public void teach() {
        System.out.println("老师在授课");
    }
    public void eat() {
        System.out.println("老师在吃饭");
    }
    public void sleep() {
        System.out.println("老师在睡觉");
    }
}
```

### 3.2 通过对象调用方法

```java
public class Test {
    public static void main(String[] args) {
        Teacher t = new Teacher();
        t.name = "张三";
        t.age = 30;
        System.out.println(t.name + " " + t.age);

        t.teach();   // 老师在授课
        t.eat();     // 老师在吃饭
        t.sleep();   // 老师在睡觉
    }
}
```

### 3.3 综合示例：厨师

```java
public class Cook {
    String name;
    int age;
    int cooklevel;

    public void cooking() {
        System.out.println(" cook is cooking ");
    }
}
```

**方法书写格式：**
```
修饰符 返回值类型 方法名(参数列表) { 方法体 }
```
JavaBean 中常见的简单方法写法：`public void 方法名() { ... }`。

## 四、封装：private 与 set/get

**对应文件：`opptest5/Dog.java` + `opptest5/Test.java`**

### 4.1 为什么要封装

若属性直接暴露，外界可以赋值任意非法数据（如年龄 `-1`）。把属性 **`private`** 化，再通过方法对外提供受控访问，就是封装。

### 4.2 标准封装写法

```java
public class Dog {
    // 私有化属性
    private String name;
    private int age;

    // setName：给 name 赋值
    public void setName(String value) {
        name = value;
    }
    // getName：取出 name
    public String getName() {
        return name;
    }

    // setAge：内部做合法性校验
    public void setAge(int num) {
        if (num >= 0 && num <= 15) {
            age = num;
        } else {
            System.out.println("当前的" + num + "不合理");
        }
    }
    public int getAge() {
        return age;
    }

    public void eat() {
        System.out.println(age + "岁的" + name + "正在吃吃吃");
    }
}
```

### 4.3 测试类的调用

```java
Dog d = new Dog();
d.setName("旺财");
d.setAge(3);
System.out.println(d.getName() + " " + d.getAge());   // 旺财 3
d.eat();
```

**命名规范：**
- `set` + **属性名首字母大写**：`setAge`、`setName`
- `get` + **属性名首字母大写**：`getAge`、`getName`
- `set` 方法一般需要参数、无返回值；`get` 方法无参数、有返回值。
- **需要在赋值时做校验，就把校验写在 `set` 方法里。**

## 五、this 关键字：区分成员变量与局部变量

**对应文件：`opptest6/Student.java` + `opptest6/Test.java`**

### 5.1 变量重名问题

当方法的**参数名（局部变量）** 与类的**成员变量**同名时，直接写变量名会**优先局部变量**，导致成员变量没被赋值。

```java
public class Student {
    private String name;
    private int age;

    public void setName(String name) {
        this.name = name;   // this.name：成员变量；name：局部变量
    }
    public String getName() {
        return name;
    }
    // 若形参名与成员变量不同名，可以省略 this：
    public void setAge(int num) {
        age = num;
    }
    public int getAge() {
        return age;
    }
}
```

### 5.2 `this` 的含义

- `this` 指向**当前调用该方法的对象**。
- 常见用途：**区分同名的成员变量与局部变量**，最典型场景是 set 方法。

### 5.3 使用对象属性进行计算

```java
Student s = new Student();
s.setName("武明坤");
s.setAge(18);
s.setHeight(175);
s.setWeight(65);

// 通过 getter 读出，再算好写回 setter
s.setAge(s.getAge() + 1);          // 长了一岁
s.setWeight(s.getWeight() + 10);   // 体重 + 10
```

**要点：** 修改成员变量的常用套路 —— `s.setXxx(s.getXxx() + 变化量)`。

## 六、构造方法（Constructor）

**对应文件：`opptest7/Student.java` + `opptest7/Test.java`；`opptest8/Student.java` + `opptest8/Test.java`**

### 6.1 什么是构造方法

构造方法在 **`new` 创建对象时由 JVM 自动调用**，用于给对象做初始化工作（如给成员变量赋值）。

**格式：**
```java
修饰符 类名(参数列表) { 方法体 }
```
方法名与类名**完全一致**，**没有返回值类型**。

### 6.2 无参 + 全参构造方法（推荐都写）

```java
public class Student {
    private String name;
    private int age;
    private int height;
    private int weight;

    // 空参构造
    public Student() { }

    // 全参构造（用 this. 区分参数与成员变量）
    public Student(String name, int age, int height, int weight) {
        this.name = name;
        this.age = age;
        this.height = height;
        this.weight = weight;
    }

    // set / get 方法略
}
```

**IDEA 快捷键：** 在类中按 `Alt + Insert` → 选择 `Constructor`，可自动生成构造方法。

### 6.3 调用与规则

```java
public class Test {
    public static void main(String[] args) {
        // 无参构造：属性使用默认值
        Student s = new Student();
        System.out.println(s.getName() + " " + s.getAge());

        // 全参构造：一次性完成赋值
        Student ss = new Student("张三", 18, 175, 75);
        System.out.println(ss.getName() + " " + ss.getAge()
                + " " + ss.getHeight() + " " + ss.getWeight());
    }
}
```

### 6.4 构造方法的重要规则

1. **构造方法在 `new` 时由 JVM 自动调用**，不能像普通方法那样手动 `obj.Student()` 调用。
2. 若**没有定义任何构造方法**，系统会**自动提供一个默认的无参构造**。
3. 一旦**手写了任意构造方法**（哪怕是有参的），系统就**不再提供默认无参构造**。
    - 因此习惯上：**空参 + 全参两个构造方法都要显式写出来**，方便配合 `new Student()` 与 `new Student("张三", 18)` 两种写法。
4. 无参构造与带参构造**方法名相同、参数不同**，属于**方法重载（Overload）** 的一种。

### 6.5 综合示例：Student 类模板

**对应文件：`opptest8`**，这是标准 JavaBean 的最终形态：

```java
public class Student {
    // 1. 私有属性
    private String name;
    private int age;

    // 2. 构造方法（空参 + 全参）
    public Student() { }

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 3. set / get
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    // 4. 成员方法（行为）
    public void study() { System.out.println("学习"); }
    public void sleep() { System.out.println("睡觉"); }
    public void eat()   { System.out.println("吃"); }
}
```

```java
Student stu2 = new Student("张三", 18);
System.out.println(stu2.getName() + " " + stu2.getAge());
stu2.eat();
stu2.sleep();
stu2.study();
```

## 七、JavaBean 标准书写规范总结

一个规范的 JavaBean 类，代码组织顺序：

1. **私有成员变量**（`private 类型 变量名;`）
2. **构造方法**：**空参 + 全参**都要写
3. **set / get 方法**：为每个属性提供，命名 `setXxx` / `getXxx`
4. **成员方法（行为）**：不写 `static`

对应的测试类 `Test`：
- 在 `main` 中用 `new` 创建对象
- 通过 `对象名.属性`（未封装时）或 `setXxx/getXxx`（封装后）读写属性
- 通过 `对象名.方法名()` 调用行为
