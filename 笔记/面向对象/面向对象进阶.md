## 一、static 修饰成员变量（静态变量）

**对应文件：`staticvariabletest/Student.java`、`staticvariabletest/Test.java`**

### 1.1 共享 vs 不共享

同一个类的多个对象，成员变量分为两类：

| 类型 | 修饰 | 特点 |
|------|------|------|
| 实例变量 | 无 `static` | **不共享**，每个对象各有一份 |
| 静态变量 | `static` | **共享**，被该类所有对象共同持有 |

```java
public class Student {
    // 不共享：每个学生各自的名字、年龄
    String name;        // 学生姓名
    int age;            // 学生年龄

    // 共享：全体学生共用同一位老师
    static String teacherName;  // 老师姓名
}
```

### 1.2 static 的核心特性

- **共享**：赋值只需一次；只要有一个对象修改了，其他对象看到的值都会随之改变。
- **归属**：静态变量不属于某个对象，而是**属于整个类**。
- **生命周期**：随着类的加载而加载，**优于对象而存在**，只要类被加载，它就一直在方法区内存中存在。

### 1.3 调用方式

```java
// 方式一：通过对象名调用（不推荐）
stu1.teacherName = "晓雯老师";

// 方式二：通过类名调用（推荐）
Student.teacherName = "晓雯老师";
```

```java
Student.teacherName = "晓雯老师";   // 用类名直接赋值，全体共享

Student stu1 = new Student();
stu1.name = "张施施";
stu1.age = 18;

Student stu2 = new Student();
stu2.name = "王丹丹";
stu2.age = 19;

// 两个对象输出的 teacherName 相同，因为它是共享的
System.out.println(stu1.name + " " + stu1.age + " " + Student.teacherName);
System.out.println(stu2.name + " " + stu2.age + " " + Student.teacherName);
```

> **要点：** 判断一个属性该不该加 `static`，就看它是否"被该类所有对象共享"。像老师姓名这种全体一致的数据才用 `static`，名字、年龄这种因人而异的不能用。

## 二、final 关键字

**对应文件：`finaltest/FinalTest1.java`、`finaltest/FinalTest2.java`、`finaltest/Circle.java`、`finaltest/Student.java`**

### 2.1 final 修饰变量 → 常量

**特点：**
1. **一旦赋值就不能再改变**。
2. 常量名**大写**，多个单词之间用**下划线**连接（如 `MAX_VALUE`）。

```java
final int num = 10;
System.out.println(num);      // 10
System.out.println(num - 6);  // 4
// num = 200;  // ❌ 编译错误，不能修改 final 修饰的变量
```

### 2.2 final 对"基本类型"与"引用类型"的不同含义（⚠️ 易错）

| 数据类型 | 举例 | final 锁定的内容 |
|---------|------|-----------------|
| 基本数据类型 | `final int a = 10;` | 变量里记录的**数值**无法改变 |
| 引用数据类型 | `final Student s = new Student();` | 变量里记录的**地址**无法改变，但**对象内部的属性值仍可修改** |

```java
// final 修饰引用类型：地址不能变，但对象内容可以变
final Student STU = new Student("张三", 18);
STU.setAge(20);                 // ✅ 允许，修改的是对象里的属性
System.out.println(STU.getAge());   // 20
// STU = new Student();          // ❌ 不允许，不能改变 STU 指向的地址
```

### 2.3 用 final 定义常量：圆的 JavaBean

**需求：** 定义一个描述圆的类，属性：半径、圆周率；方法：计算面积、计算周长。

圆周率 `PI` 是固定不变的，用 `final` 修饰，防止被误改；同时只提供 `get` 不提供 `set`。

```java
public class Circle {
    private double radius;            // 半径（可变）
    private final double PI = 3.14;   // 圆周率（常量，不可变）

    public Circle() {}
    public Circle(double radius) { this.radius = radius; }

    public double getRadius() { return radius; }
    public void setRadius(double radius) { this.radius = radius; }
    public double getPI() { return PI; }   // 只读，无 setPI

    public double getArea()   { return PI * radius * radius; }  // 面积
    public double getLength() { return 2 * PI * radius; }       // 周长
}
```

```java
Circle c = new Circle(1.5);
System.out.println(c.getRadius() + "," + c.getPI());  // 1.5,3.14
System.out.println(c.getArea());    // 7.065
System.out.println(c.getLength());  // 9.42
```

## 三、枚举（enum）

**对应文件：`enumtest/OrderState.java`、`enumtest/EnumTest1.java`、`enumtest/EnumTest2.java`**

### 3.1 为什么用枚举

**场景：** 电商订单的状态是有限的几种固定取值（待支付、处理中、已发货……）。用枚举可以把"一组合法的常量值"集中定义成一个类型，避免用魔法字符串/数字，也便于 `switch` 匹配。

### 3.2 定义枚举类

```java
public enum OrderState {

    // 第一行必须把枚举项（对象）全部罗列出来，逗号分隔，分号结尾
    PAYMENT_PENDING("待支付"),
    PROCESSING("处理中"),
    SHIPPED("已发货"),
    OUT_FOR_DELIVERY("配送中"),
    DELIVERED("已送达"),
    CANCELLED("已取消");

    private String name;

    // 构造方法默认 private，就算不写编译器也会自动加上
    private OrderState() {}
    private OrderState(String name) { this.name = name; }

    public String getName() { return name; }
}
```

### 3.3 使用枚举与 switch 匹配

```java
// 获取枚举类对象：直接 类名.枚举项
OrderState o1 = OrderState.PAYMENT_PENDING;
System.out.println(o1.getName());   // 待支付

// switch 匹配时，case 直接写枚举项名字（不加类名前缀）
switch (o1) {
    case PAYMENT_PENDING  -> System.out.println("待支付");
    case PROCESSING       -> System.out.println("处理中");
    case SHIPPED          -> System.out.println("已发货");
    case OUT_FOR_DELIVERY -> System.out.println("配送中");
    case DELIVERED        -> System.out.println("已送达");
    case CANCELLED        -> System.out.println("已取消");
}
```

### 3.4 枚举的注意事项（⚠️ 重点）

1. 每一个枚举项，都是该枚举类的**对象**，每个对象都通过构造方法创建。
2. 枚举类在底层就是常量，默认由 `public static final` 修饰。
3. 枚举类的**第一行必须是枚举项**，枚举项用逗号分隔、**分号结尾**。
4. 枚举类的构造方法可以是 `private`（私有的），不让外部创建对象。

### 3.5 编译器自动新增的两个方法：values() 与 valueOf()

| 方法 | 作用 |
|------|------|
| `values()` | 获取当前枚举类**所有枚举项**组成的数组 |
| `valueOf("名称")` | 获取指定名称的枚举项，等价于 `OrderState.名称` |

```java
OrderState o1 = OrderState.PROCESSING;
System.out.println(o1.getName());   // 处理中

// values()：遍历所有枚举项
OrderState[] arr = OrderState.values();
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// valueOf()：按名字取出某个枚举项
OrderState shipped = OrderState.valueOf("SHIPPED");
System.out.println(shipped);        // SHIPPED
```

## 四、静态方法与现代工具类

**对应文件：`toolclasstest/ArrayUtil.java`、`toolclasstest/Test.java`**

### 4.1 static 修饰方法（静态方法）的注意事项

- **静态方法**只能访问静态变量和其他静态方法。
- **非静态方法**可以访问静态变量/静态方法，也可以访问非静态变量/非静态方法。
- **静态方法里没有 `this` 关键字**（因为它不属于某个对象）。

### 4.2 工具类的写法规范

工具类把一堆常用的静态方法集中在一起，供全局直接调用。要点：

1. 方法用 `static` 修饰 → 可以直接用 `类名.方法名()` 调用，无需创建对象。
2. **构造方法私有化**（`private`）→ 禁止外部 `new`，因为它只是方法的中转站。

```java
public class ArrayUtil {

    private ArrayUtil() {}   // 构造私有化，工具类不允许被实例化

    // 遍历打印数组，格式：[1,2,3]
    public static void printArr(int[] arr) {
        System.out.print("[");
        for (int i = 0; i < arr.length; i++) {
            if (i == arr.length - 1) {
                System.out.println(arr[i] + "]");   // 最后一个元素后跟 ]
            } else {
                System.out.print(arr[i] + ",");     // 其余后面跟逗号
            }
        }
    }

    // 求平均分
    public static double getAverage(int[] arr) {
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];
        }
        return sum * 1.0 / arr.length;   // ×1.0 转成 double，避免整数除法丢精度
    }
}
```

```java
int[] arr1 = {1, 2, 3, 4, 5};
ArrayUtil.printArr(arr1);          // [1,2,3,4,5]

int[] arr2 = {3, 4, 5, 6, 7};
// IDEA 快捷键：选中方法调用按 ctrl + alt + v，自动生成左边的接收变量
double average = ArrayUtil.getAverage(arr2);
System.out.println("平均值为：" + average);   // 平均值为：5.0
```

> **陷阱：** `sum * 1.0 / arr.length` 中的 `* 1.0` 不能省。若写成 `sum / arr.length`，两个 int 相除结果为 int（小数部分被截断），平均分算不准。
