## 一、继承（extends）

### 1.1 继承的概念与语法

**对应文件：`oop_extends/test1/Person.java`、`Student.java`、`Teacher.java`、`Test.java`**

- **继承**：面向对象的三大特征之一，子类可以继承父类的属性和方法。
- **作用**：代码复用，提高代码的可维护性。
- **语法**：`class 子类名 extends 父类名 { // 子类自己的属性和方法 }`

```java
// 父类
public class Person {
    String name;
    int age;
    public void eat() { System.out.println(name + "正在吃"); }
}

// 子类 Student 继承 Person
public class Student extends Person {
    String grade;
    public void study() { System.out.println(name + "正在学习"); }
}

// 子类 Teacher 继承 Person
public class Teacher extends Person {
    String subject;
    public void teach() { System.out.println(name + "正在教" + subject); }
}
```

```java
Student s = new Student();
s.name = "张斯斯";  // 直接访问从父类继承的属性
s.age  = 18;
s.grade = "高三";
s.eat();    // 调用父类方法
s.study();  // 调用自己的方法
```

### 1.2 继承的传递性（多层继承）

**对应文件：`oop_extends/test2/SmartDevice.java`、`Phone.java`、`Computer.java`、`Android.java`、`Apple.java`、`Test.java`**

继承链：`SmartDevice ← Phone ← Android/Apple`、`SmartDevice ← Computer`。

```java
public class SmartDevice { String brand; double price; }
public class Phone      extends SmartDevice { public void call(){...} public void sendMessage(){...} }
public class Computer   extends SmartDevice { public void coding(){...} }
public class Android    extends Phone       { public void nfc(){...} }
public class Apple      extends Phone       { }        // 空子类也合法，继承全部父类成员
```

```java
Android a = new Android();
a.brand = "Xiaomi";  a.price = 1999;
a.nfc(); a.call(); a.sendMessage();   // 孙子类可访问祖父类的成员
```

> **要点：** 子类不仅继承直接父类，还继承父类的所有祖先类和子孙类新增的成员，形成"金字塔"式结构。

### 1.3 成员变量同名：`this` 与 `super`（⚠️ 易混淆）

**对应文件：`oop_extends/test3/Fu.java`、`Zi.java`、`Test.java`**

当父子类中定义了**同名变量**时，取值遵循就近原则：

| 写法 | 含义 |
|------|------|
| `变量名` | **就近**：本方法局部变量 → 本类成员 → 父类成员 |
| `this.变量名` | 本类的成员变量 |
| `super.变量名` | 父类的成员变量 |
| `Outer.this.变量名` | 内部类中访问外部类成员（详见内部类章节） |

```java
public class Fu { String name = "Fu show"; }

public class Zi extends Fu {
    String name = "zi";
    public void ziShow() {
        String name = "ziShow";
        System.out.println(name);        // ziShow  → 局部
        System.out.println(this.name);   // zi      → 本类成员
        System.out.println(super.name);  // Fu show → 父类成员
    }
}
```

### 1.4 方法重写（Override）

**对应文件：`oop_extends/test4/Gen1Phone.java`、`Gen2Phone.java`、`Gen3Phone.java`、`Test.java`**

**场景：** 第三代手机在打视频电话时"升级"了父类的 `call()`。

```java
public class Gen1Phone { public void call() { System.out.println("打电话"); } }
public class Gen2Phone extends Gen1Phone { public void sendMS() { ... } }

public class Gen3Phone extends Gen2Phone {
    @Override   // 注解：编译期校验是否真的重写了父类方法（IDEA 可 alt+enter 自动生成）
    public void call() {
        System.out.print("开启视频");
        System.out.println("打电话");
    }
    public void playGame() { ... }
}
```

**`@Override` 的作用：** 加上后如果签名与父类不一致，编译器会报错，避免"自以为重写了其实没重写"。

### 1.5 重写的注意事项与 `super.方法()` 复用父类逻辑

**对应文件：`oop_extends/test5/SmartDevice.java`、`Phone.java`、`Test.java`**

**需求：** 智能设备按价格打折（0-1000 不打折、1000-5000 九折、5000-10000 八折、10000+ 七折）；手机在此基础上再打九折。

```java
public class SmartDevice {
    public double payment() {
        if      (price >= 0     && price <  1000) return price;
        else if (price >= 1000  && price <  5000) return price * 0.9;
        else if (price >= 5000  && price < 10000) return price * 0.8;
        else if (price > 10000)                    return price * 0.7;
        else { System.out.println("输入价格有误"); return 0; }
    }
}

public class Phone extends SmartDevice {
    @Override
    public double payment() {
        double payment = super.payment();   // ← 复用父类结果再升级
        return payment * 0.9;
    }
}
```

**方法重写三大注意：**
1. 父类代码完全不用 → 子类直接重写完整逻辑。
2. 父类代码要在其基础上升级 → 用 `super.方法名()` 拿到父类结果再加工。
3. **被 `private` / `static` / `final` 修饰的方法不能被重写。**

### 1.6 子类构造方法与 `super()`

**对应文件：`oop_extends/test6/Person.java`、`Student.java`、`Teacher.java`、`Test.java`**

```java
public class Person {
    String name; int age;
    public Person()                  { System.out.println("Person的无参构造方法"); }
    public Person(String name,int age){ this.name=name; this.age=age;
                                        System.out.println("Person的有参构造方法"); }
}

public class Student extends Person {
    String grade;
    public Student() { System.out.println("Student的无参构造方法"); }
    public Student(String name, int age, String grade) {
        super(name, age);         // ← 手动调用父类有参构造
        this.grade = grade;
        System.out.println("Student的有参构造方法");
    }
}
```

**继承构造方法四条细节：**
1. 子类构造方法第一行**默认存在一个 `super()`**，用于调用父类无参构造，JVM 自动加上。
2. 想调用父类**有参**构造，必须手动写 `super(参数)`，不能省略。
3. 创建子类对象时，**先执行父类构造，再执行子类构造**。
4. `super()` / `super(参数)` **必须写在构造方法的第一行**。

### 1.7 `this()`：构造方法之间互相调用

**对应文件：`oop_extends/test7/Student.java`、`Test.java`**

**需求：** 学生默认姓名"同学"、默认年龄 18。

```java
public class Student {
    String name; int age;
    public Student()          { this("同学", 18); }   // ← this() 调用本类其他构造
    public Student(String name, int age) {
        this.name = name; this.age = age;
    }
}
```

**`this()` 使用细节：**
- 作用：**调用本类的其他构造方法**，避免重复代码。
- 如果子类多个构造之间用 `this()` 互相调用，**必须至少保留一个构造方法用 `super(...)` 调用父类**。
- 写了 `this()` 就不能再写 `super()`，系统也不会自动添加。
- `this()` 必须放在构造方法的**第一行**。

### 1.8 继承案例：本科/硕士学生 & 通识/专业课老师

**对应文件：`oop_extends/test8/Person.java`、`Student.java`、`BachelorStudent.java`、`MasterStudent.java`、`Teacher.java`、`GeneralTeacher.java`、`MajorTeacher.java`、`Test.java`**

继承树：

```
                Person（name/age/eat/sleep）
              /                          \
        Student                          Teacher
        (grade, study)                   (subject, teach)
        /        \                        /       \
  Bachelor   Master              General    Major
  Student   Student              Teacher    Teacher
```

```java
public abstract class Person { ... 略 ... }         // 实际源码里 Person 非 abstract
public class Student extends Person { private String grade; public void study(){...} }

public class BachelorStudent extends Student {
    public BachelorStudent(String name,int age,String grade){ super(name,age,grade); }
    @Override public void study() { System.out.println("攻读学士学位"); }
}
public class MasterStudent extends Student {
    public MasterStudent(String name,int age,String grade){ super(name,age,grade); }
    @Override public void study() { System.out.println("攻读硕士学位"); }
    @Override public void sleep() { System.out.println("在豪华版学生公寓睡觉"); }
}
```

> **训练点：** 属性抽到父类，行为差异通过子类 `@Override`；`private` 属性通过父类 `getXxx()` 提供给子类使用（如 `getSubject()`）。

### 1.9 权限修饰符（继承可见性对照表）

**对应文件：`oop_extends/test9/AccessModifiers.java`**

| 修饰符 | 本类 | 同包 | 子类 | 任意 |
|--------|:----:|:----:|:----:|:----:|
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（空着不写） | ✅ | ✅ | ❌（不同包子类也不行） | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

- `private`：只能在**当前类**中访问。
- 默认：**当前包**内可访问。
- `protected`：当前包 + **不同包的子类**可访问。
- `public`：所有类都能访问，不限制包和类。

## 二、抽象类（abstract）

### 2.1 抽象类与抽象方法的语法

**对应文件：`oop_abstract/test1/Animal.java`、`Cat.java`、`Dog.java`、`Test.java`**

```java
public abstract class Animal {
    private String name; private String color;
    // 构造方法、get/set 略

    // 抽象方法：只有方法声明、没有方法体，强制子类重写
    // IDEA 中在子类里 alt+enter 可自动生成重写
    public abstract void eat();

    public void drink() { System.out.println("喝水"); }
}

public class Dog extends Animal {
    @Override public void eat() { System.out.println("狗吃肉"); }
    public void lookHome() { System.out.println("狗看家"); }
}
```

### 2.2 抽象类四大注意点（⚠️ 重点）

1. **抽象类不能实例化**（不能 `new Animal()`）。
2. **抽象类中不一定有抽象方法；有抽象方法的类一定是抽象类。**
   - 只加 `abstract` 但不写抽象方法的作用：**不让外界创建本类对象**。
3. **抽象类中可以有构造方法**，作用：给成员变量赋值（子类 `super(...)` 用）。
4. **抽象类的子类**：要么重写所有抽象方法，要么子类本身也是抽象类（意义不大）。

### 2.3 适配器类（解决"不想全部重写"的问题）

**对应文件：`oop_abstract/test2/Fu.java`、`FuAdapter.java`、`Zi.java`**

**问题：** 父抽象类有 5 个抽象方法，但子类只想重写其中一个。

**解法：** 中间加一层**适配器抽象类**，把父类所有抽象方法先"空实现"，子类按需再重写。

```java
public abstract class Fu {
    public abstract void method1();
    public abstract void method2();
    public abstract void method3();
    public abstract void method4();
    public abstract void method5();
}

// 适配器：把 5 个抽象方法全部空重写
public abstract class FuAdapter extends Fu {
    @Override public void method1() {}
    @Override public void method2() {}
    @Override public void method3() {}
    @Override public void method4() {}
    @Override public void method5() {}
}

// 真正使用时：只想重写 method3 就重写 method3
public class Zi extends FuAdapter {
    @Override public void method3() { /* 自定义 */ }
}
```

> **要点：** 适配器模式让"必须全部重写"变成"想重写哪个就重写哪个"。

## 三、接口（interface）

### 3.1 接口的定义与多实现

**对应文件：`oop_interface/test1/Animal.java`、`Swim.java`、`Dog.java`、`Frog.java`、`Rabbit.java`、`Test.java`**

```java
// 抽象类：Animal
public abstract class Animal {
    private String name; private String color;
    // 构造、get/set 略
    public abstract void eat();
}

// 接口：Swim（额外能力）
public interface Swim {
    public abstract void swim();
}

// 子类既继承父类，又实现接口
public class Frog extends Animal implements Swim {
    @Override public void eat()  { System.out.println("青蛙吃虫子"); }
    @Override public void swim() { System.out.println("青蛙正在蛙泳"); }
}

// 兔子不需要游泳能力，就不实现 Swim
public class Rabbit extends Animal {
    @Override public void eat() { System.out.println("兔子吃胡萝卜"); }
}
```

> **意义：** 抽象类刻画"是什么"（is-a），接口刻画"能做什么"（has-the-ability）。游泳是可插拔的能力，用接口最合适。

### 3.2 接口中成员的特点

**对应文件：`oop_interface/test1/Test.java`、`oop_interface/test2/Inter.java`、`Student.java`**

| 成员 | 特点 |
|------|------|
| 成员变量 | 默认 `public static final`（**必须赋值**，即常量） |
| 构造方法 | **没有** |
| 成员方法 | JDK7 及以前只能是抽象方法；<br>JDK8 起允许 `default` 默认方法、`static` 静态方法；<br>JDK9 起支持 `private` 方法 |

```java
public interface Inter {
    int A = 10;   // 等价于 public static final int A = 10;
    // 不能写构造方法
}

// 使用：直接用接口名访问常量
System.out.println(Inter.A);   // 10
```

### 3.3 类与类、类与接口、接口与接口的关系

**对应文件：`oop_interface/test3/Inter1.java`、`Inter2.java`、`Interimpl.java`、`Person.java`、`Test.java`**

| 关系 | 支持情况 |
|------|---------|
| 类 ↔ 类（继承 `extends`） | **只能单继承**，不能多继承，但可以**多层继承** |
| 类 ↔ 接口（实现 `implements`） | 可**单实现**、可**多实现**；还可以在继承一个类的同时实现多个接口 |
| 接口 ↔ 接口（继承 `extends`） | 可**单继承**，也可**多继承** |

```java
public class Interimpl extends Person implements Inter1, Inter2 {
    // Inter1: method1 / method2
    @Override public void method1() {...}
    @Override public void method2() {...}
    // Inter2: function1 / function2
    @Override public void function1() {...}
    @Override public void function2() {...}
}
```

**注意：**
- 如果父类也是抽象类，子类要把所有抽象方法（父类 + 接口的）都重写，否则子类必须是抽象类。
- 多个接口中出现**同名抽象方法**时，**只需重写一次**。
- 接口 A 继承了多个接口 → 相当于把所有父接口的抽象方法都继承下来，实现 A 时必须全部重写。

### 3.4 综合案例：教练/运动员 + 会说英语

**对应文件：`oop_interface/test4/Person.java`、`Coach.java`、`Sporter.java`、`English.java`、`BasketballCoach.java`、`PingPangCoach.java`、`BasketballSporter.java`、`PingPangSpoter.java`、`Test.java`**

- **Person**：抽象类（防止外界 `new Person`），持有 `name/age`。
- **Coach / Sporter**：Person 的抽象子类，分别有 `teach()`、`study()` 抽象方法。
- **English**：接口，额外能力 `speakEnglish()`。
- 会英语的乒乓球教练 / 运动员：既继承具体岗位类，又实现 `English`。

```java
public abstract class Person { private String name; private int age; ... }
public abstract class Coach   extends Person { public abstract void teach(); ... }
public abstract class Sporter extends Person { public abstract void study(); ... }
public interface  English                     { public abstract void speakEnglish(); }

public class PingPangCoach  extends Coach   implements English {
    @Override public void teach()        { System.out.println("教练正在教乒乓球"); }
    @Override public void speakEnglish() { System.out.println("教练正在说英语"); }
}
```

> **分层技巧：** "共性 → 抽象类"、"能力 → 接口"，让"篮球教练"这类不需要英语的角色不用实现 `speakEnglish()`。

### 3.5 默认方法（default）

**对应文件：`oop_interface/test5/Inter.java`、`InterImpl.java`、`Test.java`**

- **作用：** 为接口升级而存在（新增方法时不破坏已有实现类）。
- **格式：** `public default 返回值类型 方法名(参数列表) { ... }`
- **注意事项：**
  1. 默认方法**不是抽象方法**，不强制重写；但一旦重写要去掉 `default` 关键字。
  2. `public` 可省略，`default` **不能省略**。
  3. 实现多个接口且它们有**同名默认方法**时，子类**必须重写**该默认方法。

```java
public interface Inter {
    public abstract void method1();
    public abstract void method2();

    public default void function() {
        System.out.println("接口中新增的默认方法");
    }
}

public class InterImpl implements Inter {
    @Override public void method1() {...}
    @Override public void method2() {...}
    // function() 可选重写，若不重写就直接继承
}
```

```java
Inter ii = new InterImpl();
ii.function();   // 通过接口引用调用默认方法
```

### 3.6 静态方法与私有方法（JDK 8/9 新增）

**对应文件：`oop_interface/test6/Inter.java`、`Test.java`**

**接口中的静态方法：**
- 作用：与默认方法一样，用于接口升级。
- 格式：`public static 返回值类型 方法名(参数) { ... }`
- **只能通过接口名调用**，不能通过实现类名或对象名调用；`public` 可省，`static` 不能省。

**接口中的私有方法（JDK 9）：**
- **普通私有方法**：抽取默认方法中的重复代码。
- **静态私有方法**：抽取静态方法中的重复代码。

```java
public interface Inter {
    public default void login() {
        check1();
        System.out.println("执行登录的逻辑~");
    }

    public static void register() {
        check2();
        System.out.println("执行注册的逻辑~");
    }

    // 普通私有方法：给 default 复用
    private void check1() {
        System.out.println("检查网络~");
        System.out.println("检查用户名和密码的格式~");
        System.out.println("检查用户名是否存在~");
    }

    // 静态私有方法：给 static 复用
    private static void check2() {
        System.out.println("检查网络~");
        System.out.println("检查用户名和密码的格式~");
        System.out.println("检查用户名是否存在~");
    }
}
```

> **陷阱：** 私有方法只能被同接口内的 `default` / `static` 方法调用，实现类和外界都拿不到。

## 四、内部类（Inner Class）

### 4.1 为什么用内部类

**对应文件：`oop_innerclass/demo1/Car.java`、`Test.java`**

**需求：** 描述汽车，属性含"品牌/价格/颜色"以及"发动机的品牌/使用年限"。发动机是汽车的一部分，把 `Engine` 写在 `Car` 内部，结构更清晰。

```java
public class Car {
    String carBrand;
    int    carAge;
    String carColor;

    // 内部类：发动机
    class Engine {
        String engineBrand;
        int    engineAge;
    }
}
```

> **意义：** 将外部类的成员进行分类，让类结构更清晰。
> **定义格式：** `访问修饰符 class 内部类名称 { ... }`（写在另一个类的大括号内部）。

### 4.2 成员内部类的注意点与获取方式

**对应文件：`oop_innerclass/demo2/Outer.java`、`Test.java`**

**注意点：**
1. 成员内部类可以被 `private` / 默认 / `protected` / `public` / `static` 等修饰符修饰。
2. **JDK 16 之前成员内部类里不能定义静态变量；JDK 16 起才可以。**

**获取成员内部类对象的两种方式：**

| 方式 | 说明 |
|------|------|
| 方式一 | 外部类提供 `public` 方法，把 `private` 内部类对象暴露出去（推荐） |
| 方式二 | 直接创建：`外部类.内部类 对象名 = new 外部类对象().new 内部类();` |

```java
public class Outer {
    String name;
    private class Inner { static int a = 10; }    // JDK16+ 才允许
    public Inner getInner() { return new Inner(); }
}

// 链式编程直接访问外部类字段
System.out.println(new Outer().name);

// 通过外部类方法拿到私有内部类对象
Outer o = new Outer();
Object oi = o.getInner();
System.out.println(o.getInner());
```

### 4.3 成员内部类中访问同名变量：`Outer.this`

**对应文件：`oop_innerclass/demo3/Outer.java`、`Test.java`**

```java
public class Outer {
    private int a = 10;

    class Inner {
        private int a = 20;
        public void show() {
            int a = 30;
            System.out.println(a);              // 30 → 局部变量
            System.out.println(this.a);         // 20 → 内部类的成员
            System.out.println(Outer.this.a);   // 10 → 外部类的成员
        }
    }
}

public class Test {
    public static void main(String[] args) {
        Outer.Inner oi = new Outer().new Inner();
        oi.show();
    }
}
```

> **技巧：** `外部类名.this.成员` 用来在内部类里明确指向外部类对象，与 1.3 节的 `super` 逻辑一致——就近原则。

### 4.4 静态内部类

**对应文件：`oop_innerclass/demo4/Outer.java`、`Test.java`**

```java
public class Outer {
    int a = 10;
    static int b = 20;

    static class Inner {
        public void show1() {
            Outer outer = new Outer();          // 想要非静态，必须自己造对象
            System.out.println(outer.a);
            System.out.println(b);              // 静态成员可直接访问
            System.out.println("非静态方法被调用");
        }
        public static void show2() { System.out.println("静态方法被调用"); }
    }
}
```

```java
// 创建对象：外部类名.内部类名 对象名 = new 外部类名.内部类名();
Outer.Inner oi = new Outer.Inner();
oi.show1();

// 静态方法：外部类名.内部类名.方法名();
Outer.Inner.show2();
```

**注意事项：**
1. 静态内部类也是**成员内部类**的一种。
2. **只能直接访问外部类中的静态变量和静态方法**；要访问非静态成员，需要额外创建外部类对象。

### 4.5 局部内部类

**对应文件：`oop_innerclass/demo5/Outer.java`、`Test.java`**

```java
public class Outer {
    int b = 20;

    public void show() {
        int a = 10;

        // 定义在方法内部的类：局部内部类
        class Inner {
            String name; int age;
            public void method1() {
                System.out.println(b);   // 访问外部类成员 ✅
                System.out.println("method1");
            }
            public void method2() { System.out.println("method2"); }
        }

        Inner i = new Inner();   // 只能在方法内创建并使用
        System.out.println(i.name);
        System.out.println(i.age);
        i.method1();
        i.method2();
    }
}
```

**特点：**
1. 定义在方法里就叫**局部内部类**，作用范围类似局部变量。
2. **外界无法直接使用**，必须在方法内部创建对象使用。
3. 该类可以**直接访问外部类成员**，也可以**访问方法内的局部变量**。

### 4.6 匿名内部类

**对应文件：`oop_innerclass/demo6/Swim.java`、`Test.java`**

- **作用：** 少定义一个 Java 文件。
- **使用场景：** 需要一个类来实现多态，但这个类**只用一次**。
- **格式：**

```java
new 类名 / 接口名() {
    重写方法
};
```

```java
public interface Swim { public abstract void swim(); }

public class Test {
    public static void main(String[] args) {
        // 方式一：直接把匿名对象作为实参传入
        goSwimming(new Swim() {
            @Override public void swim() { System.out.println("匿名内部类实现多态"); }
        });

        // 方式二：先用匿名对象赋值给父接口引用，再传入
        Swim s = new Swim() {
            @Override public void swim() { System.out.println("匿名内部类实现多态"); }
        };
        goSwimming(s);
    }

    public static void goSwimming(Swim s) { s.swim(); }
}
```

> **理解：** `new Swim(){...}` 中的大括号代表一个"没有名字的 Java 类"，它实现了 `Swim`；`new` 创建该无名类的实例对象。
